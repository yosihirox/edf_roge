# EDF ローグライト・ディフェンス

EDF6（地球防衛軍6）の兵科と装備をモチーフにした、ブラウザだけで遊べるタワーディフェンス型ローグライトです。
個人で遊ぶためのファンメイド作品で、商用利用はしません。

## 遊び方

公開URL: https://yosihirox.github.io/edf_roge/ （`main` へのプッシュで GitHub Actions が自動デプロイ）

手元では `index.html` をブラウザで開くだけで動きます（サーバー不要・ビルド不要）。

1. タイトルで作戦地域（マップ3種）と難易度（EASY / NORMAL / HARD / INFERNO）を選んで「出撃」
2. 最初に「初期装備」を3枚のカードから1枚選ぶ
3. 下のボタンで兵科を選び、経路以外のマスをクリックして隊員を配置（SPを消費）
4. 「ウェーブ開始」で敵が出現。ベースの耐久が0になると作戦失敗
5. 敵を倒すと経験値が入り、**Lvが上がるたびに3枚のカードから強化を1つ選択**
6. ウェーブ20のボスを倒せば作戦成功（その後エンドレスで続行も可能）

| 操作 | 内容 |
|---|---|
| クリック | 配置 / 隊員を選択 |
| Shift+クリック | 同じ兵科を連続配置 |
| 1〜4 | 兵科を選択 |
| Space | ウェーブ開始 |
| F / P | 速度切替 / 一時停止 |
| S / Delete | 選択中の隊員を回収（60%返金） |
| 右クリック / Esc | キャンセル |

## 兵科

| 兵科 | 役割 | 初期武器 |
|---|---|---|
| レンジャー | 安価な万能型。対空も可能 | AF-14 |
| ウイングダイバー | 高火力。エネルギー切れで緊急チャージ（射撃不能） | レイピア |
| フェンサー | 重装甲。周囲の敵を引き付ける盾役 | ブラストホール・スピア |
| エアレイダー | 支援要請で範囲攻撃。周囲の味方を回復 | 攻撃機 機銃掃射 |

同じ兵科を配置するたびにコストが上がります。倒れた隊員は「救護中」になり、一定時間で復帰します。

## カード（強化パーツ）

- **武器換装**: 兵科の武器を EDF6 の武器に変更（例: ストリンガーJ9、ライジン、ガリオン速射機関砲、スプライトフォール、キラーコプター4）
- **補助装備**: リバーサー、ZE-GUN、プラズマコア、ブリンク・ボール、ディフレクション・シールド、ライフベンダー、警護・カプセル など
- **強化 / 補給**: 攻撃力・耐久・射程・SP など

レアリティはコモン / レア / エピック。配置済みの兵科のカードが出やすくなります。

## ラン間の持ち越し

敵がまれに落とす緑の箱（アーマー）は作戦終了時に持ち帰られ、次回以降の全隊員の耐久が上がります（最大+100%）。
記録はブラウザの localStorage に保存されます。

## 画像素材（ローカル生成）

画像が無くても図形で描画されるので、そのまま遊べます。
`assets/img/<key>.png` を置くと自動でその画像に差し替わります。素材の一覧とプロンプトは `assets/manifest.js` にあります。

ローカルの ComfyUI で一括生成するスクリプトを用意しています。

```bash
# ComfyUI を起動した状態で
pip install pillow            # 任意: 白背景の透過・リサイズ
python tools/comfy_generate.py --list
python tools/comfy_generate.py                  # 未生成の素材を全部生成
python tools/comfy_generate.py --only unit_ranger,enemy_antBlack --overwrite
python tools/comfy_generate.py --ckpt Illustrious-XL-v2.0.safetensors
```

- 公式絵を参考にしたいときは、`assets/reference/<key>.png` に参考画像を置くと img2img で生成します（`--denoise 0.5〜0.7` 推奨）。参考画像は `.gitignore` 済みでコミットされません。
- 隊員と敵のスプライトは「右向き・横視点・白背景」で生成し、スクリプトが白背景を透過します。ゲーム内では進行方向に合わせて左右反転します。
- 背景は 800×480、カードのアイコンは `card_<武器キー>` で 256×256 に縮小されます。

```
assets/manifest.js  画像素材リストと生成プロンプト
tools/comfy_generate.py  ComfyUI 一括生成スクリプト
```
