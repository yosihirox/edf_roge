# 企画書（ドラフト）：女の子オートバトル・サバイバー系ローグライト

本人の時間つぶし用。やりこみ要素を多くする。キャラアートは本人が別途用意。

## コアコンセプト
- 操作は移動だけ、攻撃はすべてオート
- 1回のプレイ時間は固定にしない（ボス出現は必須ではない）
- ブラウザで遊べる（GitHub Pagesで公開）。描画はWebGL（PixiJS等）で大量の敵に対応し、iPhoneはホーム画面に追加して全画面アプリとして遊ぶ（PWA）
- スマホの縦画面・片手操作にも対応
- 敵が画面を埋め尽くすほど出る、大量撃破の爽快感重視
- 世界観はこだわらない（魔法少女・ファンタジー・SFなど混在OK）
- パーティ：メイン1人（操作）＋サポート1人（自動追従）
- 絵柄：ドット絵必須ではない。イラスト（ComfyUIで生成）を縮小したスプライトで進める

## 成長・メタ進行
- レベルアップ時に3枚のカードから1つ選んで強化
- プレイで拾ったコインで永続強化（HP・攻撃力など）を購入
- 永続強化はスキルツリー型（枝分かれマップを埋める）
- キャラごとの個別レベル（使うほど強くなる）
- 装備品（アクセサリー等）がドロップ、ランダム効果付き（ハクスラ風）
- 拠点（ホーム画面）の施設を育てて新機能を解放
- 実績達成で新キャラ・新武器を解放
- 転生：強さをリセットする代わりに永続ボーナス
- 呪いシステム：自分で難易度を上げるほど報酬アップ
- （不採用：放置報酬）

## キャラ
- 最初は3人、最終的に20人以上
- キャラごとの専用初期武器
- キャラごとの固有パッシブ能力
- ゲージ式の必殺技ボタン1つ（唯一の手動操作）
- 衣装（スキン）収集
- 衣装ごとの小さな性能ボーナス
- （不採用：好感度、連携ボーナス、キャラストーリー、隠しキャラ）

## 武器・進化
- 武器最大6個＋パッシブアイテム最大6個
- 武器を最大レベル＋特定アイテム所持で「進化」
- 武器2つを合体させる「融合進化」
- 武器の種類は40以上（剣・魔法弾・ビーム・召喚・設置・オーラなど）
- 炎・氷・雷などの属性と敵の弱点
- ステータスが上振れした「レア武器」
- レベルアップ選択肢の「振り直し」「封印」
- 宝箱のルーレット演出でまとめて複数強化
- 進化レシピ図鑑
- 縛りプレイ（例：武器1種類のみ）で専用報酬

## ステージ・敵
- ステージは5つ以上、それぞれ雰囲気が違う（森・氷原・廃都市・宇宙など）
- 無限に広がるマップ（端がない）
- 時間経過で敵が強く多くなり、規定時間を生き残ればステージクリア（「死神」役の強制終了はなし）
- 数分おきに中ボス、倒すと宝箱
- 群れが隊列で押し寄せる「ラッシュ」イベント
- ステージごとのハード版（クリアで解放）
- 敵の種類を多く（遠距離・自爆・分裂など）
- （不採用：迷路型ステージ、壊せるオブジェ、ランダムイベント）

## 方針
- 買い切り型。スタミナ・ガチャ・デイリー・ウィークリーなど運営型の要素は入れない
- やりこみはエンドコンテンツ（クリア後に遊び続けられる高難度・育成）で作る

## エンドコンテンツ（すべて「あれば良い」扱い。開発状況によって削ってよい）
- 記録室：図鑑（敵・武器・アイテム）・実績・統計・ベスト記録をひとまとめ
- 素材で装備を強化・合成する鍛冶屋
- 全ステージ最高難度クリアで最終称号
- 深淵モード：階層を下るほど敵が強くなる、終わりなし
- 全ステージクリア後の裏ボス
- 呪い（難易度）は上限なし、最高到達段階を記録
- 装備レア度6段階、最上位は特殊効果付き
- 装備効果の付け替え・厳選
- ダメージ数値のインフレ（最終的に億単位）
- ボスラッシュ

## 演出・遊びやすさ
- ヒット時の画面揺れ・ヒットストップなどの手応え演出
- 大量撃破時に経験値の宝石がまとめて吸い込まれる演出
- ダメージ数字表示のON/OFF
- 軽量モード（演出を減らす、古いスマホ向け）
- いつでも一時停止、中断セーブから再開
- 倍速ボタン（1.5倍・2倍）
- 効率よく稼げる手段は用意する（例：素材やコインが多く出る短時間の稼ぎステージ）
- ステージごとのBGM、ボス戦専用曲
- 必殺技で立ち絵カットイン
- セーブデータのファイル書き出し・読み込み
- （不採用：オート周回。買い切りなので自分で遊んで稼ぐ）
